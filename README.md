**Key highlights:**

- 🪪 Built **eKYC as three separate SDKs** — Flutter, native Android (Kotlin, Jetpack Compose) and native iOS (Swift) — used in bank onboarding apps and in the **POCKET** and **upay** mobile wallets
- 🏦 Built a **server-driven onboarding SDK** (every form field rendered from the server) used by **7+ banks**, and the bKash onboarding package used in the **bKash Merchant app (1M+ downloads)**

- 🧪 Write unit, widget and integration tests; release to the App Store and Google Play
